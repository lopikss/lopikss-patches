## 🎮 XP Hero — Exchange materials

**Target:** XP Hero v26.2.0 (`io.supercent.weaponrpg`), Android XAPK.

**Patch:** `XP Hero: Zero-gem Exchange materials`

- Attempts to change **24 gem-priced Upgrade and Enhancement material offers** on the Exchange tab to **0 gems**.
- Does **not** change ad-based daily freebies, paid Google Play purchases, or other unrelated shop items.
- Refuses to patch a different version of the underlying Unity shop data (SHA-256 safety check).
- **Disabled by default**; turn it on manually in Morphe's Expert mode.
- **Not yet tested on a real device**; server-side or gameplay checks may still reject the exchange.

See [technical details and testing notes](docs/XP_HERO_EXCHANGE.md).

## 📲 Install with Morphe (Android)

1. Install [Morphe](https://morphe.software).
2. Tap **[Add Lopikss Patches](https://morphe.software/add-source?github=lopikss/lopikss-patches)**, or open Morphe → **Sources** → **+** → **Remote**, then enter `github.com/lopikss/lopikss-patches`.
3. Until the new version is stable, open the **Lopikss Patches** source card and enable **Pre-release patches**. Also enable **Experimental app versions** if that option appears. Tap **Update**.
4. Turn on **Expert mode** under **Settings → Advanced → Expert settings**.
5. Choose **XP Hero**, then select **v26.2.0**. When prompted, provide the **original, unmodified XAPK**; do not use an APK already patched with other patches.
6. Under the **Lopikss Patches** tab, enable **XP Hero: Zero-gem Exchange materials**, then tap **Proceed to patching**.
7. After the patcher reports success, **save/export the patched APK**. Install only after protecting your original game data.

> [!CAUTION]
> On unrooted Android, the patched APK will normally have a **different signing certificate**. Installing it over the original app can require uninstalling the original game, which **deletes its local app data**. Back up progress and make sure you can restore it **before** proceeding. If you cannot back up safely, do not uninstall the game just to test this patch.

In-game: open **Exchange → Upgrade material / Enhancement material**. Report whether prices display as zero and whether you can exchange without your gem balance going down. If patching fails, share the Morphe **patcher log** with personal information removed.

Morphe's own guides: [Manage patch sources](https://github.com/MorpheApp/morphe-manager/blob/main/docs/patch-sources.md) · [Expert mode patching](https://github.com/MorpheApp/morphe-manager/blob/main/docs/patching-expert-mode.md).

## 🛠️ Development

This project uses the [Morphe patch template](https://github.com/MorpheApp/morphe-patches-template). Work goes to `dev`; `main` is the public stable branch.

```bash
git clone https://github.com/lopikss/lopikss-patches.git
cd lopikss-patches
./gradlew :patches:buildAndroid
```

Patches are compiled into a `.mpp` bundle in `patches/build/libs/`. **Do not commit proprietary game APKs or Unity binary assets.**
